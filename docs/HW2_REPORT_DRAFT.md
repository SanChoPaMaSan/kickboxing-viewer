# HW2 보고서 초안 — STRIKE LAB

**프로젝트:** 3D 킥복싱 기술 뷰어 / **작성자:** 제출 시 학번·이름 기입

**개발 목적**  
취미인 킥복싱을 소프트웨어 개발과 연결하여, 기술 카드를 선택하면 3D 캐릭터가 동작하는 웹 서비스를 제작하였다. 사용자는 잽, 스트레이트, 좌우 훅·어퍼컷·미들킥·로우킥 총 10개 기술을 다양한 시점에서 관찰할 수 있다. 이 프로젝트는 AI 보조 개발과 GitHub 기반 자동 배포 과정을 실습하기 위해 기획하였다.

**기술 구성 및 구현**  
React와 TypeScript로 UI를 구성하고 Three.js로 전신 캐릭터, 바닥, 조명과 그림자를 구현하였다. 외부 모델 대신 직접 만든 관절형 모델을 사용하며, 준비·타격·회수 구간을 보간하고 역기구학으로 관절 위치를 계산한다. 왼쪽 카드에는 캐릭터의 왼손·왼발 기술을, 오른쪽 카드에는 오른손·오른발 기술을 배치하였다. 재생·일시정지·반복·속도 변경 및 카메라 회전·확대 기능을 제공하며 모바일에서는 캐릭터 아래에 두 열로 카드를 배치한다.

**개발 및 검증**  
AI와 함께 잽 시제품을 먼저 구현하고 브라우저에서 확인한 다음 10개 기술로 확장하였다. 자동 검사에서 동작 이동량과 다리 도달 범위 문제를 발견하여 수정했다. 기술 개수·좌우 구성, 정확한 가드 복귀, 좌표 연속성, 선택한 부위의 이동, 타격 높이 차이, 관절 길이를 검사하는 6개 테스트를 통과하였다. 타입 검사와 프로덕션 빌드도 통과하였다. 실제 브라우저에서는 10개 카드 선택과 타격 순간, 연속 선택, 재생 제어, 카메라 조작, 390px 모바일 배치를 확인하고 캡처를 저장하였다.

**자동 배포 구성 및 현재 상태**  
main 브랜치 push 시 GitHub Actions가 의존성 설치, 테스트, 타입 검사, 빌드와 GitHub Pages 배포를 수행하도록 워크플로를 작성하였다. 저장소 하위 경로에서 사용할 수 있도록 상대 에셋 경로로 빌드한다. 현재 로컬 구현·검증 및 워크플로 작성까지 완료하였으며, 원격 저장소 생성·push·공개 배포는 아직 수행하지 않았다. 제출 전 실제 배포 결과와 저장소·서비스 URL을 추가해야 한다.

**한계 및 개선 방향**  
캐릭터와 동작은 단순화된 시각화이며 전문 자세 교정이나 실제 인체 역학을 보장하지 않는다. 향후 라이선스가 명확한 정교한 리깅 모델과 전문가 검토 동작으로 교체하고 콤비네이션 기능을 추가할 수 있다.
